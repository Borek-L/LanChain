LanChat

风雨传声 - 去中心化内网通讯工具

v1.0 P2P 架构 Python

快速启动

# 进入 src 目录并启动
$ cd src
$ python main/main.py

首次运行会提示输入昵称和端口（默认 9000），之后自动读取 config.ini。

命令速查

命令用途示例
/who查看在线用户/who
/chat按昵称/IP 发消息/chat Alice 你好
/msg给最近联系人发消息/msg 在吗
/whois查看最近联系人/whois
/file发送文件/file Alice ./doc.pdf
/history聊天记录/history Alice
/nick修改昵称/nick Bob
/exit退出程序/exit

最简流程

> /who                          # 1. 看谁在线
> /chat Alice 你好！             # 2. 发消息
> /msg 下午开会吗？               # 3. 继续聊（自动发给最近联系人）

防火墙配置

协议端口用途
UDP9000用户发现 + 聊天消息
TCP9000文件传输
IGMP-组播发现（必须）

Windows (PowerShell 管理员)

New-NetFirewallRule -DisplayName "LanChat UDP" `
  -Direction Inbound -Protocol UDP `
  -LocalPort 9000 -Action Allow
New-NetFirewallRule -DisplayName "LanChat TCP" `
  -Direction Inbound -Protocol TCP `
  -LocalPort 9000 -Action Allow

Linux (ufw)

sudo ufw allow 9000/udp
sudo ufw allow 9000/tcp

Linux (firewalld)

sudo firewall-cmd --permanent --add-port=9000/udp
sudo firewall-cmd --permanent --add-port=9000/tcp
sudo firewall-cmd --reload

技术架构

层级技术说明
用户发现UDP 组播224.1.1.1:9000，心跳 5s，超时 30s
即时聊天UDP 单播点对点消息，端口 9000
文件传输TCP端口 9000，4096B/块
配置持久化INI 文件config.ini
聊天记录内存存储进程退出即丢失

注意事项

所有用户必须在同一局域网内。组播不跨网段，跨 VLAN 需配置 IGMP Proxy。聊天记录仅存内存，退出即清空。收到的文件保存在 src/main/LanChat/received/ 目录。
